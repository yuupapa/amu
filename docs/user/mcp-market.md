# MCP（Amu）

**設定 → 連携 → MCP** で、外のサービスの MCP サーバーを追加できます。追加したサービスは、Amu の中の Claude と Codex の会話で使えます。Claude と Codex それぞれに設定し直す必要はありません。

## 追加する

1. 使いたいサービスの「追加する」を押します。
2. ログインが必要なサービスでは、ブラウザーにそのサービスのログイン画面が開きます。ログインして、Amu からのアクセスを許可します。
3. 「つながりました」と出たらタブを閉じます。設定の欄が「接続済み」に変わります。

Context7 はログインが要らないので、押すとすぐに追加されます。

## いつから使えるか

- **これから始める会話:** すぐに使えます。
- **いま開いている会話:** Amu を再起動したあとに使えます。会話ごとに、使えるサービスの組み合わせを開いた時点で決めているためです。
- **「外す」を押したとき:** その場で止まります。開いている会話から呼んでも、Amu が断ります。

## 安全のための決まり

- ログインの鍵は Amu が預かり、Claude や Codex には渡しません。AI は Amu を中継してサービスを使います。
- 計画モードの会話と、読み取り専用で動いている会話では、ツールの実行を Amu が止めます。Codex の「承認あり（Supervised）」も読み取り専用で動くので止まります。ツールの一覧を見ることはできます。
- それ以外の会話では、各 AI の許可設定に従います。Claude で「この会話では許可」と答えた場合や、Claude の起動設定で確認をなくしている場合は、確認なしで使われます。
- 追加と削除は、この Mac の Amu からだけできます。スマホやブラウザーから開いた設定では、状態を見るだけです。
- Claude や Codex が自分の中で動かす子エージェントは、親の会話と同じ権限で使います。

## 状態の表示

- **接続済み:** 使えます。
- **もう一度ログインが必要:** ログインの期限が切れたか、サービス側で取り消されました。「もう一度ログイン」を押します。
- **一時的に使えません:** サービスにつながりませんでした。少ししてから会話で使い直すか、新しい会話を始めます。

## 一覧に出るサービス

Amu でのログインと、Claude・Codex からの呼び出しを確かめ終えたサービスだけが一覧に出ます。候補は Vercel、HyperFrames、Supabase、Linear、topview、Context7 です。

## 会話の中での名前

Claude と Codex の会話では、追加したサービスが `amu-mcp-<サービス>-<6 文字>` という名前で見えます（例：`amu-mcp-linear-3fa2c1`）。最後の 6 文字はこの Mac の Amu ごとに決まるので、ご自身の Claude や Codex の設定にある MCP サーバーと名前が重なることはありません。

## 使える AI

いまは Claude と Codex の会話だけです。Cursor、Grok、OpenCode、Pi の会話では使えません。
