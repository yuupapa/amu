# Amuの使い方

アプリ内では「設定 → 一般 → Amuの使い方・ヘルプ」から機能を検索できます。設定画面の検索でも「ヘルプ」「音声」「Creator」などで探せます。

## 会話・AI選択

Claude Code、Codex、Cursorなどを一つの画面で使えます。会話の途中でAIを切り替えられます。

頼み方・始め方の例: 「同じ会話を別のAIで続ける」

使うエージェントのCLIを入れ、ログインしておきます。

## オート

新しい会話の最初の依頼に合わせて、使えるモデルと思考の強さを選びます。

頼み方・始め方の例: モデル選択の杖アイコンから「オート」を選ぶ

判定役へのログインが必要です。添付やスラッシュコマンドを使うときは手動で選びます。

## Amu Creator

動画や編集可能なHyperFramesプロジェクトを開き、映像を見ながら修正コメントを送れます。

頼み方・始め方の例: 「この動画プロジェクトをCreatorで開いて。字幕を編集できる状態にして」

デスクトップ版の「設定 → 連携」でAmu Creator（試験版）を有効にします。編集するプロジェクトの場所を指定してください。MP4だけを開く場合は、字幕などの編集には元のプロジェクトが必要です。

## Amu Audio

ナレーション・BGM・効果音をチャット内で再生し、テイクを聞き比べるためのプレーヤーです。

頼み方・始め方の例: 「この音声をAmu Audioで聞き比べられるようにして」

Amu Audioスキルの導入が必要です。ナレーションや音楽の生成には別途対応サービスなどが必要で、料金やログイン条件はサービスによって異なります。

## Amu Gallery

登録した生成画像や動画をAmu内で開いて確認できます。

頼み方・始め方の例: 「生成した画像をGalleryで見せて」

デスクトップ版の「設定 → 連携」でAmu ギャラリーを有効にします。画像や動画をギャラリーに登録してから開きます。生成には対応する外部ツールが必要です。

## ブラウザで確認

共有プレビューでWebページを開き、AIと同じページを見ながら確認できます。

頼み方・始め方の例: 「このURLをプレビューで開いて、表示を確認して」

ログインが必要なページでは、対象のアカウントやブラウザの状態を確認します。

## 画面分割・更新

会話を最大4つまで左右・上下に並べられます。新しいバージョンが出ると、右上の通知からアプリを更新できます。

頼み方・始め方の例: 「サイドバーのスレッドを会話画面へドラッグする」

更新通知が出たら、画面の案内に沿ってダウンロードと再起動を行います。

使える機能は接続や設定によって異なります。使えないときは「今の環境でこの機能を使えるか確認して。必要な接続や準備を教えて」とチャットで頼んでください。
