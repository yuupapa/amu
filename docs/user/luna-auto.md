# オートでモデルを選ぶ

モデル選択を開き、左の列の杖のアイコン（お気に入りの下）を押すと「オート」になります。新しい会話の最初の依頼を送ると、つながっている AI が判定役になり、使えるモデルと思考の強さを選びます。選んだ結果は「オート（Haikuが判定）：Sonnet 5.5・低 — 理由」のように、判定役の名前と短い理由と一緒に表示されます。そのあと通常の送信処理へ渡します。判定中は送信ボタンが回るマークになり、入力欄の上の「判定を取り消す」で止めることもできます。続きの会話では、選ばれたモデルをそのまま使います。

## 判定役の順番

判定役は、次の順でつながっているものから選びます（2026-10-08、結パパの方針）。

1. Claude Haiku 5.5（Claude のサブスクでログインしているとき）
2. GPT-6 Luna（Codex CLI で ChatGPT にログインしているとき）
3. Composer 2.5（Cursor のアカウントでログインしていて、`cursor-agent` があるとき）

判定役が失敗したとき（使用上限、時間切れ、答えの形が不正など）は、次の順位の判定役が判定し直します。判定は依頼を実行しないので、やり直しても依頼が二重に送られることはありません。「判定を取り消す」で止めたときは、次の判定役に回しません。3 つとも使えないときは、入力を残したまま手動送信に戻ります。

どの判定役もサブスクのログインだけを使います。API キーでの接続、Amazon Bedrock、別のエンドポイントを使う接続は判定役にしません。API 課金への切り替えや新しい認証の設定も行いません。

## 判定役ができること

判定の対象は依頼の本文だけです。添付、複数モデルの同時実行、スラッシュコマンドを使うときは、手動でモデルを選んで送信してください。判定役は依頼そのものを実行しません。アクセス設定や承認の扱いも変えません。

- Haiku は道具を一つも持たずに動きます。答えの形を決める仕組みだけを使い、ユーザーの設定・フック・MCP サーバーは読み込みません。
- Luna は読み取り専用で、道具を切った状態で動きます。
- Composer は読み取り専用の質問モードで、空のフォルダーの中で動きます。道具を使おうとした時点で止めます。

判定役が依頼の実行や道具の使用を求めた場合は、その場で止めて次の判定役に回します。

再読み込みしても判定や送信を自動でやり直すことはありません。一度オートを始めた会話ではオートを選べないので、もう一度使うときは新しい会話で送信してください。

## どの依頼にどのモデルを選ぶか

判定役は、次の表に沿って選びます（2026-10-08、結パパの方針）。第一候補が使えないときだけ次点を選びます。

| 依頼の種類                           | 第一候補                      | 次点             |
| ------------------------------------ | ----------------------------- | ---------------- |
| 軽い質問・要約・ちょっとした手直し   | GPT-6 Luna                    | Sonnet 5.5       |
| 文章（台本・記事・投稿）             | Sonnet 5.5                    | Gemini 3.8 Flash |
| 箇条書き・資料の整理                 | Sonnet 5.5                    | Opus 5.5         |
| ふつうのコード修正                   | GPT-6.1 Sol（思考は中くらい） | Sonnet 5.5       |
| コードのレビュー・事実確認・調べもの | GPT-6.1 Sol                   | Opus 5.5         |
| 複雑な設計・原因の調査               | Opus 5.5                      | GPT-6.1 Sol      |

Fable 5.1 と GPT-6 Astra はクレジットの消費が大きいので、オートでは選びません。旧世代のモデル（Opus 5、Sonnet 5、Grok 4.6 など）も外しています。表のモデルがどれも使えないときだけ Grok 4.7 を選び、それも無ければ使えるモデル全部から選びます。

表を変えたいときは、`~/Library/Application Support/Amu/runtime/userdata/luna-routing.json` を作ります。`preferred`（選んでよいモデルの一覧）、`fallback`（表のモデルが無いときの予備）、`guidance`（判定役に渡す選び方の説明）を書きます。判定役の順番を変えたいときは `judges` に `claude`、`codex`、`cursor` を好きな順で書きます。書かなかった判定役は使いません。ファイルが無いか読めないときは、上の表と順番を使います。

```json
{
  "preferred": [
    "gpt-6-luna",
    "claude-sonnet-5-5",
    "claude-opus-5-5",
    "gpt-6.1-sol",
    "gemini-3.8-flash"
  ],
  "fallback": ["grok-4.7"],
  "guidance": "依頼の種類ごとの選び方: …",
  "judges": ["claude", "codex", "cursor"]
}
```
