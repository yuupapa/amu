# オートでモデルを選ぶ

モデル選択を開き、左の列の杖のアイコン（お気に入りの下）を押すと「オート」になります。新しい会話の最初の依頼を送ると、Luna（gpt-6-luna）が使えるモデルと思考の強さを選び、短い理由を表示してから通常の送信処理へ渡します。判定中は送信ボタンが回るマークになり、入力欄の上の「判定を取り消す」で止めることもできます。続きの会話では、選ばれたモデルをそのまま使います。

判定の対象は依頼の本文だけです。添付、複数モデルの同時実行、スラッシュコマンドを使うときは、手動でモデルを選んで送信してください。Lunaはツールを使わず、依頼そのものも実行しません。アクセス設定や承認の扱いも変えません。

Lunaを使えないときや結果が不正なときは、入力を残したまま手動送信に戻ります。再読み込みしても判定や送信を自動でやり直すことはありません。一度オートを始めた会話ではオートを選べないので、もう一度使うときは新しい会話で送信してください。

利用には、Codex CLIでChatGPTにログインしていることが必要です。APIキーへの切り替えや新しい認証の設定は行いません。

## どの依頼にどのモデルを選ぶか

Luna は、次の表に沿って選びます（2026-10-08、結パパの方針）。第一候補が使えないときだけ次点を選びます。

| 依頼の種類                           | 第一候補                      | 次点             |
| ------------------------------------ | ----------------------------- | ---------------- |
| 軽い質問・要約・ちょっとした手直し   | GPT-6 Luna                    | Sonnet 5.5       |
| 文章（台本・記事・投稿）             | Sonnet 5.5                    | Gemini 3.8 Flash |
| 箇条書き・資料の整理                 | Sonnet 5.5                    | Opus 5.5         |
| ふつうのコード修正                   | GPT-6.1 Sol（思考は中くらい） | Sonnet 5.5       |
| コードのレビュー・事実確認・調べもの | GPT-6.1 Sol                   | Opus 5.5         |
| 複雑な設計・原因の調査               | Opus 5.5                      | GPT-6.1 Sol      |

Fable 5.1 と GPT-6 Astra はクレジットの消費が大きいので、オートでは選びません。旧世代のモデル（Opus 5、Sonnet 5、Grok 4.6 など）も外しています。表のモデルがどれも使えないときだけ Grok 4.7 を選び、それも無ければ使えるモデル全部から選びます。

表を変えたいときは、`~/Library/Application Support/Amu/runtime/userdata/luna-routing.json` を作ります。`preferred`（選んでよいモデルの一覧）、`fallback`（表のモデルが無いときの予備）、`guidance`（Luna に渡す選び方の説明）の 3 つを書きます。ファイルが無いか読めないときは、上の表を使います。

```json
{
  "preferred": [
    "gpt-6-luna",
    "claude-sonnet-5-5",
    "claude-opus-5-5",
    "gpt-6.1-sol",
    "gemini-3.8-flash"
  ],
  "fallback": ["grok-4.7"],
  "guidance": "依頼の種類ごとの選び方: …"
}
```
