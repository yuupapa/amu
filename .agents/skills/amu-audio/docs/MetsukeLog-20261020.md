## 前提と限界

- この記録は AIテスター1名が1回だけ操作した観察です。実ユーザーテストではありません。発話・迷い・理解度は取れていません。
- モード: acceptance（S規模）。各ステップを ok / ng / blocked / skipped で記録しました。
- 対象: `review/full.html`（音声4本埋め込み）と `amu-audio.html`（空のプレーヤー）。どちらも編集していません。
- 環境: Chrome（chrome-devtools MCP）、`python3 -m http.server` で配信（127.0.0.1:8765、終了後に停止済み）。wavesurfer.js 7.12.12 を unpkg から読み込み。

- 音が実際に聞こえるかは判定できません。HTMLMediaElement の currentTime と paused、ボタン表示、波形の progress 幅、`#now` と `#time` の文字で判定しました。
- 操作の一部は JavaScript からの click / change / input / Pointer イベントで行いました（波形シーク、速度、音量、ファイル投入）。実マウスや実タッチと完全に同じではありません。

### 環境由来の妨害（結果の解釈に関わるので先に記録）

- 観察: 再生を始めてから約2〜3秒後に、テスターが送っていない isTrusted=true の pointerdown/click が「再生」ボタン中央（clientX 113, clientY 142）に届き、再生が止まる現象が複数回起きました。新しい isolated context のタブでも再現しました。停止していないときは発生しませんでした。
- 解釈: 同じブラウザを共有する別の自動操作（並行して動いている別エージェント等）の可能性が高く、プレーヤー自身の不具合ではないと判断しました。以後の検証は、テスト用タブにだけ「テスターが許可していない trusted なポインタ/クリックを捨てる」監視を入れて行いました（対象ファイルは無改変）。監視が捨てた妨害クリックは計12回です。
- 影響: 序盤の「切替後に勝手に止まる」観察はこの妨害によるものとして結果から除外しました。

## 根本課題（最大5件）

### 1. 画面の表示と実際の再生状態が食い違う
- どこ: 速度セレクト（曲切替後に表示 1.5 / 実際 1）、再生ボタン（曲ゼロで「一時停止」表示）
- 処方: `load()` の ready で `ws.setPlaybackRate(Number($('rate').value), true)` を再適用する。再生ボタンは `tracks.length === 0` なら何もせず案内文を強調し、`ws.play()` の Promise を catch する。

### 2. 「聞き比べ」の用途に対して切替が常に頭出しで、尺も事前に分からない
- どこ: 一覧クリック・前後ボタン、一覧右端の長さ表示
- 処方: テイク同士の切替で再生位置を引き継ぐ（例: 同じ kind の曲へ切り替えるときは currentTime を維持、または「同じ位置から」トグル）。長さは読み込み時に metadata だけ先に取って全行に出す。

### 3. 失敗したときに何も教えてくれない
- どこ: 非音声ファイルの選択、壊れた音声の追加、再生できない曲
- 処方: 除外したファイル名を `#now` か一覧下に「memo.txt は音声ではないため追加していません」と出す。`ws.on('error')` で該当行に「再生できません」と表示し、選択を次の曲へ移す。

### 4. キーボードと読み上げで操作しきれない
- どこ: 一覧の li（フォーカス不可）、ドロップ区画（到達不可）、⏮⏭（aria-label なし、title のみで名前が記号）、リピート（aria-pressed なし）、音量スライダー上の Space、曲名変更の通知
- 処方: 各行を `<button>` にする（または role="option" + tabindex + Enter/Space）。file input は hidden ではなく視覚的に隠すクラスにし、label をフォーカス可能にする。⏮⏭ に `aria-label="前の曲"` 等、リピートに `aria-pressed`。Space の除外は text 系 input だけに絞る。`#now` に `aria-live="polite"`。

### 5. スマホ幅で押しにくく、読めない
- どこ: ⏮⏭（32×28px）・音量スライダー（高さ16px）、種類バッジのはみ出し、メタ行の省略
- 処方: ボタンを最小 40〜44px 四方にする。バッジは `min-width` を固定値ではなく最長ラベルに合わせ `flex-shrink:0` を付ける。メタに title を付け、選択中の行だけメタを折り返して全文表示する。
